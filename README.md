Indonesia in Numbers — a national statistics explorer: population, economy, prices, work and provinces, with real figures from BPS, the World Bank and UNDP, drawn as charts in the browser. Six pages, a metric picker, searchable and sortable province tables, and a phone layout. No network requests, no tracking.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
